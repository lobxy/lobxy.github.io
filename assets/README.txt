Portfolio Icon Assets

These are clean SVG recreations matching the visual language of the generated portfolio mockup:

- outline icons use rounded strokes
- Kotlin is a simplified mark

Important: the generated portfolio preview is a single raster image, so it does not contain the original editable icon source files. These SVGs are standalone replacements intended for implementation.
